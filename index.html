1. 让整个屏幕完全居中

大白话解释：通过 Flex 布局，让内容在屏幕的正中间，并且不出现难看的滚动条。

body {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    overflow: hidden;
}

2. 渐变文字的魔法

大白话解释：先画一个渐变背景，然后把它裁剪成文字的形状，最后把文字本身变成透明，透出背后的渐变。

.gradient-text {
    background: linear-gradient(to right, #38bdf8, #818cf8, #c084fc);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
}

3. 发光光晕的产生

大白话解释：画一个圆，给它加上极高的模糊度（blur），它就变成了柔和的光晕。

.glow {
    position: absolute;
    width: 400px; 
    height: 400px;
    background: linear-gradient(135deg, #6366f1, #a855f7);
    border-radius: 50%;
    filter: blur(120px);
}

4. 网页像滑梯一样丝滑（平滑滚动）

大白话解释：只要在 CSS 里加一行代码，点击下方链接或滚动时，网页就会平滑过渡，不再“咔哒”一下闪现。

html {
    scroll-behavior: smooth;
}

5. 按钮怎么带你“穿越”到指定位置？（锚点跳转）

大白话解释：我们给下面的盒子起个唯一的名字（ID），然后在按钮的 href 里加上 #名字。点击它，浏览器就会自动滚到那个名字所在的位置。

<!-- 这是上面的按钮 -->
<a href="#code-notes">点我滑下去</a>

<!-- 这是下面的目标区域 -->
<div id="code-notes">我在这里等你</div>

6. 如何在网页上原样显示代码？（pre 和 code）

大白话解释：网页默认会把所有空格和换行吃掉。用 <pre> 标签包裹，就能完美保留所有的缩进和代码排版。

<pre>
    <code>
        // 你的代码在这里原样展示
    </code>
</pre>

7. 为什么网页在手机上不会“缩成一团”？（移动端适配）

大白话解释：这行代码藏在网页的最开头（<head> 里）。它告诉手机浏览器：“请按照手机屏幕的真实宽度来显示网页，不要把网页缩小当成电脑网页看。”

<meta name="viewport" content="width=device-width, initial-scale=1.0">

8. 鼠标放上去为什么会有平滑的动画？（过渡效果）

大白话解释：transition 就像一个缓冲器。它让按钮变色、移动的过程变得平滑，而不是瞬间“闪”过去。:hover 则是触发条件：“当鼠标悬停时”。

.btn {
    transition: all 0.3s ease; /* 所有变化都耗时0.3秒，速度平滑 */
}

.btn:hover {
    transform: translateY(-3px); /* 鼠标放上去时，向上移动3像素 */
}

9. 为什么加了边框，盒子不会变形？（盒模型设定）

大白话解释：通常你设定一个宽度 100px 的盒子，如果再加 10px 的内边距，它会撑大到 120px。box-sizing: border-box; 改变了这个规则，让宽度包含内边距，保证页面排版不乱。

* {
    box-sizing: border-box;
}

10. 按钮之间怎么自动保持距离？（Flex 间隙）

大白话解释：在你的按钮组里，有两个按钮。加上 gap: 20px;，就会自动在两个按钮中间留出 20 像素的空隙，不用再去写复杂的 margin 边距了。

.btn-group {
    display: flex;
    gap: 20px; /* 让子元素之间保持 20px 的距离 */
}

11. 鼠标光晕是怎么画出来，且不挡鼠标点击的？（CSS 篇）

大白话解释：用 position: fixed 让光晕固定在屏幕上；用径向渐变（radial-gradient）画出中心亮、四周暗的圆形；最神奇的是 pointer-events: none;，它像给光晕穿了“隐身衣”，鼠标能直接穿透它点到背后的按钮！

#cursor-glow {
    position: fixed;
    width: 400px;
    height: 400px;
    background: radial-gradient(circle, rgba(99,102,241,0.15) 0%, rgba(0,0,0,0) 70%);
    border-radius: 50%;
    pointer-events: none; /* 让鼠标穿透这层 */
    transform: translate(-50%, -50%);
}

12. 网页是怎么知道我的鼠标在哪里的？（JavaScript 篇）

大白话解释：这是网页第一次注入“灵魂”（JavaScript）。代码开启了“监听器”（addEventListener），只要鼠标一动（mousemove），就立刻获取当前的坐标（e.clientX 和 e.clientY），然后把光晕盒子硬拽到那个坐标上。

// 1. 找到网页上的光晕盒子
const glow = document.getElementById('cursor-glow');

// 2. 开启监听：当鼠标在网页上移动时
document.addEventListener('mousemove', (e) => {
    glow.style.left = e.clientX + 'px'; // 让光晕移动到鼠标的X轴
    glow.style.top = e.clientY + 'px';  // 让光晕移动到鼠标的Y轴
    glow.style.opacity = '1'; // 显示光晕
});

13. 网页是怎么播放音乐的？（Audio 标签与事件）

大白话解释：用 <audio> 标签在网页里藏一个隐形播放器。JavaScript 开启了“点击监听器”（addEventListener），当点击头像时，它通过判断 paused 属性来决定是播放还是暂停，同时操控 CSS 类名实现旋转特效。

// 1. 获取播放按钮和隐藏的音频元素
const musicBtn = document.getElementById('music-btn');
const bgMusic = document.getElementById('bg-music');

// 2. 监听按钮的点击事件
musicBtn.addEventListener('click', () => {
    // 3. 判断音频是否处于暂停状态
    if (bgMusic.paused) {
        bgMusic.play(); // 如果是暂停，就播放音乐
        musicBtn.classList.add('playing'); // 加上旋转特效的类名
        musicBtn.innerHTML = '🎶'; // 图标变成跳动音符
    } else {
        bgMusic.pause(); // 如果是播放中，就暂停
        musicBtn.classList.remove('playing'); // 移除旋转特效
        musicBtn.innerHTML = '🎵'; // 图标恢复为普通音符
    }
});

14. 网页是怎么做到“滚动浮现”的？（AOS 库）

大白话解释：我们没有从头手写复杂的滚动监听代码，而是引入了一个叫 AOS 的轻量级库。只要在 HTML 标签里加上 data-aos="fade-up" 这个“魔法标签”，并在底部用 JS 启动它 AOS.init()，当网页滚动到该元素时，它就会自动播放动画。

<!-- 1. 给元素贴上标签 -->
<div data-aos="fade-up">我要滚动浮现</div>

<!-- 2. 在 JS 中启动它 -->
<script>
    AOS.init({
        once: false // 设置为 false，意味着每次滚动都会重新播放动画
    });
</script>

15. 不用第三方库，怎么用原生 Canvas 画粒子？

大白话解释：我们用 HTML5 的 <canvas> 开辟了一块透明画布。用 JavaScript 创建了 80 个“粒子对象”，给每个粒子分配随机的坐标、颜色和速度。然后通过 requestAnimationFrame 开启一个永不停止的动画循环，不断清空画布，计算出新位置，再重新画上去。

// 画一个发光小圆点的核心代码
this.draw = function() {
    ctx.beginPath();
    ctx.arc(this.x, this.y, this.radius, 0, Math.PI * 2);
    ctx.fillStyle = this.color;
    ctx.shadowBlur = 10; // 灵魂属性：发光特效
    ctx.shadowColor = this.color;
    ctx.fill();
    ctx.shadowBlur = 0; // 画完后关掉发光，防止连线也变粗
};

16. 粒子靠近自动连线怎么算的？（勾股定理与双循环）

大白话解释：这是最考验逻辑的地方。我们用双重 for 循环让所有粒子“两两配对”。用勾股定理算出它们之间的距离，如果距离小于 120 像素，就用 lineTo 在它们中间画一条线。距离越近，线的透明度越低（越清晰），就形成了科技感丝线。

// 1. 用勾股定理算距离
function getDistance(x1, y1, x2, y2) {
    let xDistance = x2 - x1;
    let yDistance = y2 - y1;
    return Math.sqrt(Math.pow(xDistance, 2) + Math.pow(yDistance, 2));
}

// 2. 在动画循环中两两比对连线
if (distance < 120) {
    ctx.beginPath();
    ctx.moveTo(particles[i].x, particles[i].y); // 起点
    ctx.lineTo(particles[j].x, particles[j].y); // 终点
    // 动态计算透明度，距离越近越亮
    ctx.strokeStyle = "rgba(168, 85, 247, " + (1 - distance / 120) + ")";
    ctx.lineWidth = 0.5;
    ctx.stroke(); // 真正把线画出来
}
