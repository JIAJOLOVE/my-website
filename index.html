1. 让整个屏幕完全居中

大白话解释：通过 Flex 布局，让内容在屏幕的正中间，并且不出现难看的滚动条。

body {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    overflow: hidden;
}

2. 渐变文字的魔法

大白话解释：先画一个渐变背景，然后把它裁剪成文字的形状，最后把文字本身变成透明，透出背后的渐变。

.gradient-text {
    background: linear-gradient(to right, #38bdf8, #818cf8, #c084fc);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
}

3. 发光光晕的产生

大白话解释：画一个圆，给它加上极高的模糊度（blur），它就变成了柔和的光晕。

.glow {
    position: absolute;
    width: 400px; 
    height: 400px;
    background: linear-gradient(135deg, #6366f1, #a855f7);
    border-radius: 50%;
    filter: blur(120px);
}
